PA3605 Cosmology - additional lecture materials

Below are links to HTML versions of the "additional material" notes for PA3605 Cosmology (2026/27). These are annotated versions of the mathematics presented on the board/visualiser during (some of) the lectures, in a fully-accessible format. The content is identical to the PDFs provided on Blackboard (the PDF and HTML files are both generated from the same LaTeX source), but the HTML format is accessible to screen-readers, so some of you may find this format more useful.
